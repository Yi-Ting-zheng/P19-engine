# 多项式代数无关性证明指南

> 沉淀自 Phase-M4 step2_linearIndep 实证化（2026-10-11）。
> 9 个辅助引理 + 1 个主定理的完整证明策略，覆盖 ℂ 上 ℚ-线性无关性证明的通用范式。
> 对应代码：`lean_game_theory/GameTheory/ChainM3.lean`

---

## 一、问题框架

### 1.1 目标命题

```
step2_linearIndep :
  AlgebraicIndependent ℚ ![pi, lnp] → LinearIndependent ℚ z4
```

其中 `z4 = ![1, 2πi, lnπ, π·lnπ]`（ℂ 上 4 元组）。

**直觉**：若 `π` 与 `ln π` 在 ℚ 上代数无关（无非常数多项式关系），则 `1, 2πi, lnπ, π·lnπ` 在 ℂ 上 ℚ-线性无关。

### 1.2 证明的三段结构

```
g₀·1 + g₁·2πi + g₂·lnπ + g₃·π·lnπ = 0   （gᵢ ∈ ℚ）
         ↓ 虚部分离
      g₁ = 0
         ↓ 分支讨论
    ┌─ g₃ = 0 ─→ g₀ + g₂·lnπ = 0 ─→ lnπ 超越 ⟹ g₀ = g₂ = 0
    └─ g₃ ≠ 0 ─→ 构造双变量多项式 ─→ 代数无关 ⟹ 矛盾
```

## 二、9 个辅助引理的证明策略

### 引理 1：`algebraMap_rat_coe`

```lean
theorem algebraMap_rat_coe (q : ℚ) :
    algebraMap ℚ ℂ q = ((q : ℝ) : ℂ) := rfl
```

**策略**：`rfl`（定义相等）。
**原理**：`algebraMap ℚ ℂ` 与 `↑(↑· : ℝ) : ℂ` 在 Mathlib 中是同一映射（ℚ → ℝ → ℂ 的复合）。
**坑**：不要用 `norm_cast`——`rfl` 更快且避免类型class搜索。

### 引理 2：`im_rat`

```lean
theorem im_rat (q : ℚ) : (((q : ℝ) : ℂ)).im = 0 :=
  ofReal_im (q : ℝ)
```

**策略**：直接应用 `Complex.ofReal_im`。
**原理**：任何实数嵌入 ℂ 后虚部为零。

### 引理 3：`im_rat_mul`

```lean
theorem im_rat_mul (q : ℚ) (z : ℂ) :
    ((((q : ℝ) : ℂ)) * z).im = (q : ℝ) * z.im :=
  im_ofReal_mul (q : ℝ) z
```

**策略**：直接应用 `Complex.im_ofReal_mul`。
**原理**：`(r·z).im = r·z.im`（r 为实数时）。

### 引理 4：`im_two_pi_I`（关键）

```lean
theorem im_two_pi_I : (2 * (pi : ℂ) * I).im = 2 * pi := by
  rw [mul_I_im, mul_re]
  norm_num [Complex.ofReal_ofNat]
```

**策略**：两步重写 + `norm_num`。
**原理**：
1. `mul_I_im`：`(z * I).im = z.re`
2. `mul_re`：`(r * s).re = r.re * s.re - r.im * s.im`
3. `norm_num`：化简 `(2:ℂ).re = 2`、`π.im = 0`

**坑**：`Complex.im_mul_I` 不存在，必须用 `mul_I_im`。

### 引理 5：`im_log_pi`

```lean
theorem im_log_pi : (Complex.log (pi : ℂ)).im = 0 := by
  have hpos : 0 ≤ pi := le_of_lt pi_pos'
  have h : Complex.log (pi : ℂ) = ((Real.log pi : ℝ) : ℂ) :=
    (Complex.ofReal_log hpos).symm
  rw [h]
  exact ofReal_im _
```

**策略**：将 `Complex.log` 转化为 `Real.log` 的嵌入。
**原理**：`Complex.ofReal_log : 0 ≤ x → ↑(Real.log x) = log ↑x`。
**关键**：`pi_pos' : 0 < pi` 提供 `0 ≤ pi`。

### 引理 6：`im_pi_log_pi`

```lean
theorem im_pi_log_pi : ((pi : ℂ) * Complex.log (pi : ℂ)).im = 0 := by
  have hlog : Complex.log (pi : ℂ) = ((Real.log pi : ℝ) : ℂ) :=
    (Complex.ofReal_log (le_of_lt pi_pos')).symm
  rw [hlog]
  have h : ((pi : ℂ) * (((Real.log pi : ℝ) : ℂ))).im = 0 := by
    rw [im_mul_ofReal]
    simp [ofReal_im]
  exact h
```

**策略**：复用引理 5 的转化，然后 `im_mul_ofReal`。
**原理**：`(z * ↑r).im = z.im * r`（r 为实数时）；`π.im = 0`。

### 引理 7：`smul_eq_ofReal_mul`

```lean
theorem smul_eq_ofReal_mul (q : ℚ) (z : ℂ) :
    q • z = (((q : ℝ) : ℂ)) * z := by
  rw [Algebra.smul_def, algebraMap_rat_coe]
```

**策略**：`Algebra.smul_def` 展开标量乘法，然后引理 1 化简。
**原理**：ℚ 在 ℂ 上的标量乘法 = 通过 `algebraMap` 嵌入后做复数乘法。

### 引理 8：`aeval_poly`

```lean
theorem aeval_poly (g0 g2 g3 : ℚ) :
    MvPolynomial.aeval ![pi, lnp]
      (MvPolynomial.C g0 + MvPolynomial.C g2 * MvPolynomial.X 1 +
       MvPolynomial.C g3 * MvPolynomial.X 0 * MvPolynomial.X 1) =
    (g0 : ℝ) + (g2 : ℝ) * lnp + (g3 : ℝ) * pi * lnp := by
  simp [map_add, map_mul, MvPolynomial.aeval_X]
```

**策略**：`simp` 三条引理即可。
**原理**：
1. `MvPolynomial.aeval_X`：`aeval f (X i) = f i`
2. `map_add` / `map_mul`：`aeval` 是环同态
3. `MvPolynomial.C` 嵌入为常数

**坑**：变量是 `X i` 不是 `var i`（Mathlib 4.34 API）。

### 引理 9：`poly_eq_zero_imp`（系数分离）

```lean
theorem poly_eq_zero_imp (g0 g2 g3 : ℚ) (hg3 : g3 ≠ 0)
    (hP : (MvPolynomial.C g0 + MvPolynomial.C g2 * MvPolynomial.X 1 +
           MvPolynomial.C g3 * MvPolynomial.X 0 * MvPolynomial.X 1 :
           MvPolynomial (Fin 2) ℚ) = 0) :
    False
```

**策略**：三点求值法。
**原理**：在 `(0,1)`, `(1,0)`, `(1,1)` 三点求值，得到三个线性方程：
- `(0,1)`：`g0 + g2 = 0`
- `(1,0)`：`g0 = 0`
- `(1,1)`：`g0 + g2 + g3 = 0`

解出 `g0 = g2 = g3 = 0`，与 `hg3 : g3 ≠ 0` 矛盾。

**关键 API**：
- `MvPolynomial.eval`：`(σ → R) → MvPolynomial σ R →+* R`
- `MvPolynomial.eval_C` / `MvPolynomial.eval_X`：求值行为
- `congr_arg (fun p => p.eval ![...]) hP`：从多项式等式提取求值等式

**替代方案**（已排除）：
- `MvPolynomial.coeff`：不存在（用 `p.coeff m`，deprecated）
- `Finset.sum` 展开：过于繁琐

## 三、主定理证明策略

### 3.1 虚部分离（g₁ 的消去）

```lean
have him := congr_arg (fun z : ℂ => z.im) hg'
-- him : Im(g₀·1 + g₁·2πi + g₂·lnπ + g₃·π·lnπ) = 0
rw [im_rat, im_rat_mul, im_two_pi_I, im_rat_mul, im_log_pi,
    im_rat_mul, im_pi_log_pi] at him
-- him : 0 + g₁·2π + 0 + 0 = 0
```

**原理**：
- `g₀·1` 的虚部：`im_rat` → 0
- `g₁·2πi` 的虚部：`im_rat_mul` + `im_two_pi_I` → `g₁·2π`
- `g₂·lnπ` 的虚部：`im_rat_mul` + `im_log_pi` → 0
- `g₃·π·lnπ` 的虚部：`im_rat_mul` + `im_pi_log_pi` → 0

### 3.2 g₃ = 0 分支

```lean
-- hg'0 : g₀ + g₂·lnπ = 0（在 ℝ 中）
by_cases hg2 : g 2 = 0
-- 子分支 1：g₂ = 0 ⟹ g₀ = 0（由 hreal）
-- 子分支 2：g₂ ≠ 0 ⟹ 构造 Polynomial.C g₀ + C g₂ * X 在 lnπ 消零
--            ⟹ lnπ 代数 ⟹ 与 h.transcendental 1 矛盾
```

**关键**：`h.transcendental 1` 从 `AlgebraicIndependent ℚ ![pi, lnp]` 提取 `Transcendental ℚ lnp`。

### 3.3 g₃ ≠ 0 分支

```lean
-- hP0 : C g₀ + C g₂·X₁ + C g₃·X₀·X₁ 在 (π, lnπ) 消零
-- 由 algebraicIndependent_iff：aeval ![π,lnπ] P = 0 → P = 0
-- 由 poly_eq_zero_imp：P = 0 ⟹ False
```

**关键**：`algebraicIndependent_iff` 将代数无关转化为「无多项式消零」。

## 四、通用范式总结

### 4.1 线性无关性证明模板

```
目标：LinearIndependent ℚ ![z₀, z₁, ..., zₙ]

步骤：
1. rw [Fintype.linearIndependent_iff]（有限维展开）
2. intro g hg（引入系数函数和线性组合等式）
3. 对每个 zᵢ 做 Im/Re 分离（ℂ 情形）或模分解（一般域）
4. 利用已知超越性/代数无关性消去变量
5. fin_cases i 收尾
```

### 4.2 代数无关 ⟹ 线性无关的桥梁

```lean
-- 从 AlgebraicIndependent 提取超越性
have htrans : Transcendental ℚ lnp := h.transcendental 1

-- 从超越性否定代数性
exact False.elim (htrans hlnp_alg)  -- hlnp_alg : IsAlgebraic ℚ lnp
```

### 4.3 多项式系数分离模板

```lean
-- 目标：从 P = 0 推出所有系数为 0
-- 方法：在足够多的点求值，建立线性方程组
have h_eval := congr_arg (fun p => p.eval ![...]) hP
simp only [MvPolynomial.eval_C, MvPolynomial.eval_X, ...] at h_eval
norm_num at h_eval  -- 或 linarith
```

## 五、Mathlib API 速查

| 功能 | API | 备注 |
|------|-----|------|
| 有限维线性无关展开 | `Fintype.linearIndependent_iff` | `∀ g, ∑ i, g i • v i = 0 → ∀ i, g i = 0` |
| 实数嵌入虚部 | `Complex.ofReal_im` | `(↑r).im = 0` |
| 实数乘法虚部 | `Complex.im_ofReal_mul` | `(↑r * z).im = r * z.im` |
| I 乘法虚部 | `Complex.mul_I_im` | `(z * I).im = z.re`（非 `im_mul_I`） |
| 复对数 | `Complex.ofReal_log` | `0 ≤ x → ↑(Real.log x) = log ↑x` |
| 标量乘法展开 | `Algebra.smul_def` | `r • x = algebraMap R A r * x` |
| MvPolynomial 求值 | `MvPolynomial.aeval_X` | `aeval f (X i) = f i` |
| MvPolynomial 点求值 | `MvPolynomial.eval_C` / `eval_X` | `(σ → R) → MvPolynomial σ R →+* R` |
| 代数无关展开 | `algebraicIndependent_iff` | `∀ p, aeval x p = 0 → p = 0` |
| 超越性提取 | `AlgebraicIndependent.transcendental` | `h.transcendental i : Transcendental R (x i)` |
| 超越性否定 | `Transcendental` 应用 | `htrans halg : False`（halg : IsAlgebraic） |

## 六、已知坑与规避

| 坑 | 现象 | 规避 |
|----|------|------|
| `Complex.im_mul_I` 不存在 | 编译错误 | 用 `Complex.mul_I_im` |
| `MvPolynomial.var` | 未知标识符 | 用 `MvPolynomial.X` |
| `MvPolynomial.coeff` | deprecated | 用三点求值法 |
| 双重 cast `↑↑0` | `ofReal_zero` 不匹配 | `have hzero : ((0:ℚ):ℝ):ℂ = 0 := by simp` |
| `ring_nf` 改变结合律 | `(pi * lnp)` vs `pi * lnp` | 统一陈述形式 |
| `simp at h` 闭合目标 | 后续 `exact` 报 "No goals" | 用 `rw` 或 `have` 替代 |
| 命名空间冲突 `C`/`X` | Polynomial 与 MvPolynomial 歧义 | 用限定名 `MvPolynomial.C` / `Polynomial.X` |
| `subst` 对函数应用失败 | `g 3 = 0` 非自由变量 | 用 `rw [hg3]` |

## 八、深水命题标准处理范式（Phase-M5 沉淀）

> 提炼自 π^π 超越性攻坚全流程（2026-10-11）。
> 适用对象：依赖未解决猜想（Schanuel / RH / P vs NP 等）的数学命题。

### 8.1 范式定义

**深水命题**：其证明依赖一个或多个当前数学界未解决的开放猜想的命题。

**核心区分**：
- **攻克命题本身** → 需要解决开放猜想 → 当前不可行
- **对开放命题做严谨依赖建模** → 可行、有价值、可传承 → 本范式的目标

### 8.2 三不原则

| # | 原则 | 含义 | 违反后果 |
|---|------|------|---------|
| 1 | **不假装能证明** | 禁止用幻觉式"伪证明"填充缺口 | 知识污染，不可审计 |
| 2 | **不放弃不管** | 禁止因困难而丢弃问题不建档 | 知识断层，不可传承 |
| 3 | **不越界升格** | 禁止将 EMPIRICAL 升格为 THEOREM | 真值纪律崩溃 |

**第三条路**：精确标注依赖、构建下游基础设施、为未来留接口、把"为什么不能证明"本身变成可传承的文明资产。

### 8.3 标准流程（六步）

```
步骤 1：侦察
  ├── 调研 Mathlib / 形式化库基础设施现状
  ├── 识别已有组件 vs 缺失组件
  └── 产出：基础设施缺口清单

步骤 2：路径评估
  ├── 列出所有可能的证明路径
  ├── 逐条评估可行性（依赖链深度、Mathlib 覆盖度）
  ├── 证伪无效分支（标注 FALSIFIED + 适用域）
  └── 产出：路径评估矩阵

步骤 3：条件定理占位
  ├── 将开放猜想作为显式公理引入（axiom，HYPOTHESIS 层）
  ├── 主命题写成蕴含形式：公理 → 结论
  ├── 真值层级终生锁定，不可递归升级
  └── 产出：THEOREM-COND（条件性定理）

步骤 4：下游预构建
  ├── 在公理成立的假设下，构建完整下游推导链
  ├── 每一步标注 Mathlib 依赖 + 缺口编号
  ├── 未来公理升格为定理时，下游一键激活
  └── 产出：条件证明链（Lean skeleton + 缺口标注）

步骤 5：缺口台账
  ├── 每个缺口唯一编号（GAP-OPEN-XXX）
  ├── 记录：缺口内容、所需引理、Mathlib 现状、预计难度
  ├── 定期审计：区分"推进" vs "仅做观测"
  └── 产出：可审计的缺口登记簿

步骤 6：范式沉淀
  ├── 将本次攻坚流程提炼为通用模板
  ├── 沉淀到证明指南 / 作战室归档
  ├── 供未来同类命题复用
  └── 产出：可继承的方法论文档
```

### 8.4 真值纪律（不可违反）

```
AXIOM（公理）        ← 开放猜想的显式占位，终生不改
  ↓ 不可递归升级
THEOREM-COND（条件定理） ← 依赖公理的蕴含结论
  ↓ 公理升格后自动激活
THEOREM（定理）      ← 仅当公理被证明后可达
  ↑ 不可从 EMPIRICAL 升格
EMPIRICAL（观测）    ← 数值实验，仅做侦察
```

**递归升级禁令**：多次独立 EMPIRICAL 支持 ≠ THEOREM 的充分条件。累积证据仅提高置信度，不改变真值层级。

### 8.5 难度阶梯参照

| 命题 | 状态 | 难度 | 依赖 |
|------|------|------|------|
| e 是超越数 | ✅ Hermite 1873 | 已解决 | — |
| π 是超越数 | ✅ Lindemann 1882 | 已解决 | — |
| 2^√2 是超越数 | ✅ Gelfond-Schneider 1934 | 已解决 | — |
| e^π 是超越数 | ✅ Gelfond 常数 | 已解决 | — |
| **π^π 是超越数** | ❌ 开放 | 🔴🔴 | **Schanuel 猜想** |
| **π + e 是超越数** | ❌ 开放 | 🔴 | Schanuel 猜想 |
| **e 与 π 代数无关** | ❌ 开放 | 🔴🔴🔴 | Schanuel 猜想 |
| **Schanuel 猜想** | ❌ 开放 | 🔴🔴🔴🔴 | 60 年零突破 |

**关键洞察**：经典超越数工具（Lindemann-Weierstrass / Gelfond-Schneider / Baker）全部限定在代数数输入。一旦底数、指数双双超越，工具箱直接失效——这是硬边界，不是不够聪明。

### 8.6 逻辑层风险声明

**Schanuel 猜想可能独立于 ZFC**。

若 Schanuel 猜想独立于 ZFC，则 π^π 的超越性在当前公理体系内**不可判定**——不是"暂时没证出来"，而是"无法回答"（类比连续统假设之于 ZFC）。

**对比**：黎曼猜想是 Π₁ 语句，原则上 ZFC 内可判定；π^π 超越性通过 Schanuel 猜想与指数函数一阶理论的可判定性纠缠，层级更深。

### 8.7 范式价值总结

> **不是认输，而是把"知识边界本身"作为研究对象。**
>
> 不编造不存在的证明，而是精确测绘边界，为未来的突破预留接口。
>
> 这是面对深水数学命题的第三条路：在知识边界上建立可继承的预研基础设施。哪怕一百年内 Schanuel 猜想没有进展，这份归档本身也是稳定的、可审计的研究遗产；一旦突破出现，不需要从零重建证明骨架。

**可迁移性**：e^e、e+π 等同类型深水开放命题，均可复用此范式。
