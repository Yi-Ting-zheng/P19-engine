# 多独立窗口轮换审计方案（Stage-Window Rotation）

> 关联：`docs/blueprint_v1.1.md`（四房间）· `specimens/external_corpus/Specimen-004/ipttt_contract.yaml`

## 1. 动机（三个必须隔离的理由）

1. **压缩失真**：长证明全链塞进单个上下文窗口时，长上下文压缩会丢失证明细节，
   产生隐性逻辑失真——被压缩掉的往往正是跨步骤的前置条件与边界声明。
2. **审计共偏误**：单窗口同时看到「定义、假设、主干、延拓、结论」，
   先看见结论的窗口会用结论反推过程的合理性（确认偏误在 LLM 审计中的具象）。
3. **P19 物理隔离公理**：跨域势能差只在隔离边界上产生；共享上下文 = 消除边界 = 消除相变窗口。

## 2. 与四房间的关系：两条正交轴

| 轴 | 名称 | 单元 | 隔离对象 |
|----|------|------|---------|
| 纵轴 | **观测维度**（blueprint §四房间） | F / N / S / A | 判据类型（形式/数值/语义/对抗） |
| 横轴 | **证明阶段**（本文档） | W1..W5 | 证明流程的阶段上下文 |

```
        W1 定义   W2 假设   W3 主干   W4 延拓   W5 终局
Room-F   ●         ●         ●         ●         ●
Room-N   ○         ○         ●         ●         ○
Room-S   ●         ●         ●         ●         ●
Room-A   ○         ●         ●         ●         ●
```

- 房间 = 不同维度看**同一阶段**；窗口 = 同一维度看**不同阶段**。
- 元控制器（meta-controller）是唯一持有点：跨窗口调取引理，跨房间汇总投票。

## 3. 轮换机制

1. **调度**：阶段按序轮换进入独立上下文窗口；每窗只装入本阶段材料（定义/假设/主干/延拓/终局各自成窗）。
2. **交接物**：窗口之间禁止传递全文上下文，只传**结构化引理**：
   ```yaml
   handoff:
     lemma_id: "lemma-zero-preserved"
     statement: "L(ρ,χ) = L(ρ,η)·factors = 0"
     anchor: "FiniteDeletion.lean:126"
     sha256: "..."          # 引理文本哈希，防篡改、可回放
   ```
3. **终局重推**：W5 只接收 W3/W4 的**结论引理**，不接收过程叙述——
   在无结论前文的窗口里重新核对矛盾（L=0 与 L≠0），破坏确认偏误链条。
4. **回放**：同样输入 → 同样交接序列 → 同样触发（append-only 审计要求）。
